# 扑克王国 · 找牌大冒险

一个给 4–8 岁孩子做的 **3D 扑克认知小游戏**。单文件 HTML，打开即玩，不联网、不安装。

👉 **在线玩**：https://yjw94ss.github.io/poker-kingdom/

---

## 玩什么

牌桌上摊开一副三维卡牌，顶部任务条会告诉你这一关要找什么：

| 关卡 | 考点 | 任务 |
|---|---|---|
| 1–3 | 认**花色** | 找出所有红桃 / 黑桃 / 梅花 |
| 4–5 | 认**点数** | 找出所有的 7 / 所有的 K |
| 6–7 | 读**整张牌** | 找出黑桃 A；找出红桃 Q 和方块 J |
| 8 | **记忆配对** | 牌背朝下，翻出两张一样的牌 |

### 设计上的几个刻意选择

- **点错不惩罚，而是改名**。点到 ♣J 时牌会抖动红闪，同时语音说「这是梅花杰克，再找找」。错误本身就是一次教学。
- **每张牌都会说话**。点任何一张牌都会念出它的名字，识字量不足的孩子也能玩。
- **「认牌本」自由模式**。随时可切出去，把 12 张牌当图鉴随便点着听。
- **难度靠牌数而不是靠限时**。没有倒计时、没有失败，错了重来就好。

## 技术

- three.js r158（UMD 内联），全部贴图由 Canvas 2D 在运行时程序化绘制，**零外部资源**
- 牌面 / 牌背 / 边框都是运行时生成，单文件 716 KB
- WebAudio 合成音效 + SpeechSynthesis 中文语音，均在用户手势后解锁
- localStorage 存档（关卡进度 / 星星 / 分数），不可用时自动降级
- 自适应 320×568 到 1440×900，含横屏

## 本地运行

直接双击 `index.html` 即可。或用任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```
