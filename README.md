# 扑克王国 · 找牌大冒险

一个给 4–8 岁孩子做的 **3D 扑克认知小游戏**。单文件 HTML，打开即玩，不联网、不安装。

👉 **在线玩**：https://yjw94ss.github.io/poker-kingdom/

---

## 两种玩法

### 一、闯关模式（8 关）

牌桌上摊开一副三维卡牌，顶部任务条会告诉你这一关要找什么：

| 关卡 | 考点 | 任务 |
|---|---|---|
| 1–3 | 认**花色** | 找出所有红桃 / 黑桃 / 梅花 |
| 4–5 | 认**点数** | 找出所有的 7 / 所有的 K |
| 6–7 | 读**整张牌** | 找出黑桃 A；找出红桃 Q 和方块 J |
| 8 | **记忆配对** | 牌背朝下，翻出两张一样的牌 |

### 二、连连看（3 局）

首页点「连连看」进入。规则和纸面连连看一样：**点两张相同的牌，连线转弯不超过 2 次（可以绕到牌阵外面）就能消掉**，把整盘消光就过关。

- **开局必给活路**：满盘时相同牌容易互相挡住，所以发牌时会试最多 120 种排列，保证一上来就有若干个可消对，避免孩子开局就卡住。
- **卡住了自动救**：一旦无解，自动把剩下的牌重排并提示「没有能消的牌了，帮你重排一下」，永远不会走进死局。
- **连线有光效**：白芯 + 金中层 + 橙外晕三层叠加，沿路径逐段生长，消掉时读牌名。

## 难度（三档，首页切换）

难度不是一个「牌数 × 系数」，而是同时改**量**和**干扰牌长得像不像**——认牌真正难的地方是区分相似的牌，不是数牌堆有多少张。

| | 轻松（3–5 岁） | 普通（5–7 岁） | 挑战（7 岁+） |
|---|---|---|---|
| 桌面牌数（第 1 关 / 第 3 关 / 第 7 关） | 8 / 9 / 12 | 10 / 15 / 18 | 12 / 20 / 24 |
| 每关目标数 | 2 | 3 | 4 |
| 找红桃时，干扰牌里「方块」占比 | 约 17–29% | 约 43–50% | 约 63–69% |
| 找 7 时，干扰牌里「6 和 8」占比 | 0% | 约 8% | 约 50% |
| 记忆关对数 / 翻错后停留 | 3 对 / 1.9s | 4 对 / 1.35s | 6 对 / 0.7s |
| 连连看三局牌数 | 8 / 12 / 16 | 12 / 20 / 24 | 16 / 24 / 30 |
| 拿三星允许错几次 | ≤3 次 | ≤1 次 | 0 次 |

要点：

- **轻松档刻意让干扰牌「一眼能分辨」**，但不至于只靠红黑颜色蒙对——仍保留约 1/5 的同色干扰，孩子还是得看形状。
- **挑战档专挑「长得像」的牌做干扰**：找红桃 Q 时桌上会混着红桃 J、红桃 K；找 7 时混着 6 和 8。点数相近按**环形**计算，所以找 K 时会避开 A（A 与 K 只差 1）。
- 同样错 2 次，轻松拿 3 星、普通 2 星、挑战只有 1 星。
- 难度记在存档里，下次打开还是上次选的。

## 设计上的几个刻意选择

- **点错不惩罚，而是改名**。点到 ♣J 时牌会抖动红闪，同时语音说「这是梅花杰克，再找找」。错误本身就是一次教学。
- **每张牌都会说话**。点任何一张牌都会念出它的名字，识字量不足的孩子也能玩。
- **「认牌本」自由模式**。随时可切出去，把牌当图鉴随便点着听。
- **难度靠牌数与干扰相似度，而不是靠限时**。没有倒计时、没有失败，错了重来就好。
- **错误提示不挡牌**。点错时提示写进任务条副标题而不是弹窗，绝不遮住孩子正要观察的那张牌。

## 技术

- three.js r158（UMD 内联），全部贴图由 Canvas 2D 在运行时程序化绘制，**零外部资源**
- 牌面 / 牌背 / 边框 / 连线光效都是运行时生成，单文件 744 KB
- 关卡牌阵按内容包围盒反解相机距离，安全区直接从 DOM 实测浮层位置，任何屏比都不被遮挡
- 牌数随难度变化后，列数按 `√(n × 屏比系数)` 选并强制整除，牌阵不会留空格
- 连连看通路判定：0 / 1 / 2 次转弯 + 绕棋盘外圈（`(rows+2)×(cols+2)` 网格，外圈恒空）
- WebAudio 合成音效 + SpeechSynthesis 中文语音，均在用户手势后解锁
- localStorage 存档（关卡进度 / 星星 / 分数 / 难度），不可用时自动降级
- 自适应 320×568 到 1440×900，含横屏与竖屏各一套连连看布局

## 本地运行

直接双击 `index.html` 即可。或用任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```
