# 扑克王国 · 找牌大冒险

一个给 4–8 岁孩子做的 **3D 扑克认知小游戏**。单文件 HTML，打开即玩，不联网、不安装。

👉 **在线玩**：https://yjw94ss.github.io/poker-kingdom/

---

## 两种玩法

### 一、闯关模式（8 关）

牌桌上摊开一副三维卡牌，顶部任务条会告诉你这一关要找什么：

| 关卡 | 考点 | 任务 |
|---|---|---|
| 1–3 | 认**花色** | 找出所有红桃 / 黑桃 / 梅花 |
| 4–5 | 认**点数** | 找出所有的 7 / 所有的 K |
| 6–7 | 读**整张牌** | 找出黑桃 A；找出红桃 Q 和方块 J |
| 8 | **记忆配对** | 牌背朝下，翻出两张一样的牌 |

### 二、连连看（3 局）

首页点「连连看」进入。规则和纸面连连看一样：**点两张相同的牌，连线转弯不超过 2 次（可以绕到牌阵外面）就能消掉**，把整盘消光就过关。

| 局 | 桌面 | 竖屏 |
|---|---|---|
| 1 | 4×3（12 张 / 6 对） | 3×4 |
| 2 | 5×4（20 张 / 10 对） | 4×5 |
| 3 | 6×4（24 张 / 12 对） | 4×6 |

- **开局必给活路**：满盘时相同牌容易互相挡住，所以发牌时会试最多 80 种排列，保证一上来至少有 3 个可消对，避免孩子开局就卡住。
- **卡住了自动救**：一旦无解，自动把剩下的牌重排并提示「没有能消的牌了，帮你重排一下」，永远不会走进死局。
- **连线有光效**：白芯 + 金中层 + 橙外晕三层叠加，沿路径逐段生长，消掉时读牌名，强化「这是哪张牌」的记忆。

## 设计上的几个刻意选择

- **点错不惩罚，而是改名**。点到 ♣J 时牌会抖动红闪，同时语音说「这是梅花杰克，再找找」。错误本身就是一次教学。
- **每张牌都会说话**。点任何一张牌都会念出它的名字，识字量不足的孩子也能玩。
- **「认牌本」自由模式**。随时可切出去，把 12 张牌当图鉴随便点着听。
- **难度靠牌数而不是靠限时**。没有倒计时、没有失败，错了重来就好。
- **错误提示不挡牌**。点错时提示写进任务条副标题而不是弹窗，绝不遮住孩子正要观察的那张牌。

## 技术

- three.js r158（UMD 内联），全部贴图由 Canvas 2D 在运行时程序化绘制，**零外部资源**
- 牌面 / 牌背 / 边框 / 连线光效都是运行时生成，单文件 733 KB
- 关卡牌阵按内容包围盒反解相机距离，安全区直接从 DOM 实测浮层位置，任何屏比都不被遮挡
- 连连看通路判定：0 / 1 / 2 次转弯 + 绕棋盘外圈（`(rows+2)×(cols+2)` 网格，外圈恒空）
- WebAudio 合成音效 + SpeechSynthesis 中文语音，均在用户手势后解锁
- localStorage 存档（关卡进度 / 星星 / 分数），不可用时自动降级
- 自适应 320×568 到 1440×900，含横屏与竖屏各一套连连看布局

## 本地运行

直接双击 `index.html` 即可。或用任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```
